# The standalone Nerd Font glyph set — the ONLY source of icon glyphs here.
# Deliberately no patched Nerd Font (ttf-firacode-nerd and friends): a patched
# build is the same family with the glyphs baked in, so it only ever duplicates
# what this package already provides, and mixing several of them is what makes
# icon widths inconsistent between apps. Plain ttf-fira-code above plus this
# covers everything — WezTerm falls back to it per-glyph on its own, waybar
# names it in its font stack, and ~/.config/fontconfig/conf.d/10-nerd-symbols.conf
# aliases monospace to it for every app that does neither.
#
# It also has to STAY declared, because it is load-bearing for yazi: yazi depends
# on the virtual `ttf-font-nerd`, which every one of the ~100 patched nerd-font
# packages provides. Drop this line and `pacman --noconfirm` satisfies yazi with
# whichever provider it sorts to first (that is how otf-atkinsonhyperlegiblemono-nerd
# arrived here) — a patched font pulled in behind your back. Declaring it puts the
# provider in the same transaction, so nothing else is chosen.
ttf-nerd-fonts-symbols-mono
xkeyboard-config

# Printing
# shared/services.txt enables cups.SOCKET, not cups.service: socket activation
# starts cupsd on the first connection and lets it stop again when idle, so the
# daemon is not sitting there on every host that never prints.
cups
# How a network printer is FOUND. CUPS does driverless IPP Everywhere discovery
# over DNS-SD, and it asks avahi-daemon for that over D-Bus — without it, only a
# directly attached USB printer shows up in the print dialog. Already present on
# giv as somebody else's dependency; declared here so it is on every host and so
# pkg-diff stops calling it drift.
#
# NOTE: avahi-daemon listens on UDP 5353. That is one more thing exposed on
# whatever network the machine is attached to (see the firewall discussion).
#
# Resolving a literal `foo.local` hostname additionally needs nss-mdns *and* an
# edit to /etc/nsswitch.conf, which this repo does not track — deliberately left
# out, because DNS-SD discovery does not need it.
avahi
