# Base system bits the Arch installation guide leaves to you. Declared here so a
# reinstall (or `archinstall` with a minimal profile) cannot silently skip them:
# without linux-firmware/sof-firmware this laptop has no Wi-Fi and no speakers,
# and without efibootmgr systemd-boot cannot be installed.
# linux-lts is a second, known-good kernel to boot from when an upgrade of
# `linux` regresses — the cheapest insurance on Arch (see MAINTENANCE.md §1).
# CPU microcode is vendor-specific and lives in packages/pacman.<hostname>.txt.

linux-firmware
sof-firmware
efibootmgr

# Gaming — lives in the [multilib] repo, which install.sh enables for you.
# `steam` depends on the virtual packages vulkan-driver, lib32-vulkan-driver and
# lib32-libgl, each with several providers. Name this host's GPU drivers
# explicitly in packages/pacman.<hostname>.txt so they are in the same pacman
# transaction — otherwise `--noconfirm` silently picks the first provider, which
# is usually another vendor's driver:
#   Intel  -> vulkan-intel  lib32-mesa lib32-vulkan-intel
#   AMD    -> vulkan-radeon lib32-mesa lib32-vulkan-radeon
#   NVIDIA -> nvidia-utils  lib32-nvidia-utils
steam
vulkan-icd-loader
lib32-vulkan-icd-loader
